# 👐 Mão na Massa

**Mão na Massa** é uma plataforma digital simples desenvolvida com **HTML**, **CSS** e **JavaScript**, criada para conectar artesãos independentes a clientes que valorizam produtos feitos à mão. O projeto promove o empreendedorismo criativo, a cultura local e a inclusão produtiva.

## 📌 Sobre o Projeto

A plataforma permite que artesãos cadastrem seus produtos com fotos, descrições e preços. Os clientes podem navegar pelo catálogo, adicionar itens ao carrinho, realizar pagamentos online e avaliar os produtos adquiridos.

## 🛠️ Tecnologias Utilizadas

- **HTML** – Estrutura das páginas
- **CSS** – Estilização e layout responsivo
- **JavaScript** – Funcionalidades interativas
- **Git & GitHub** – Versionamento e colaboração

## 🌍 Impactos

- **Econômico:** Apoia pequenos negócios e produção local.
- **Cultural:** Valoriza o artesanato regional e fortalece a identidade cultural.
